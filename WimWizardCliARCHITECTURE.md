# Архитектура WimWizardCli.ps1

## Обзор

WimWizardCli.ps1 - это мощный PowerShell-скрипт для обслуживания Windows-образов (WIM) для развертывания через SCCM/MECM. Скрипт предоставляет полный цикл для создания и обновления Windows-образов с поддержкой x64 и ARM64 архитектур.

## Основные компоненты

### 1. Параметры и конфигурация
Скрипт использует гибкую систему параметров для настройки сборки:
- **SourceFolder**: Папка с ISO-файлами Windows и языковых пакетов
- **UpdatePath**: Путь к предварительно скачанным обновлениям
- **OutputPath**: Путь для сохранения итогового WIM
- **Languages**: Языковые пакеты для внедрения
- **Architecture**: x64 или ARM64 (автоматически определяются)

### 2. Фазы обслуживания (Pipeline)

1. **Обнаружение и монтирование ISO**:
   - Автоматическое определение правильных ISO-файлов
   - Монтирование образа диска
   - Определение версии и сборки

2. **Очистка компонентного хранилища (Component Store Cleanup)**:
   - Удаление ненужных пакетов
   - Очистка CBS (Component Based Servicing)

3. **Применение обновлений (Patch Tuesday)**:
   - Скачивание обновлений с Microsoft Update Catalog
   - Двухшаговый процесс:
     - Первый проход: WinRE и SSU (System Service Upgrade)
     - Второй проход: Полный образ

4. **Внедрение языковых пакетов (Language Packs)**:
   - Использование Add-WindowsCapability для языковых пакетов
   - Поддержка до 4 языков (по умолчанию скандинавские языки)

5. **Удаление приложений (Appx Removal)**:
   - Удаление предустановленных Appx-пакетов
   - Поддержка кастомных списков через XML

6. **Внедрение Функций на запрос (FoD)**:
   - NetFx3, RSAT и другие ключи
   - Только NetFx3 поддерживается для ARM64

7. **Внедрение драйверов (Drivers)**:
   - Рекурсивное сканирование папок с INF-файлами
   - Интеграция через Add-WindowsDriver

8. **Экспорт и сжатие (Export and Compress)**:
   - Создание итогового WIM-файла
   - Автоматическое генерирование имени файла

### 3. Режимы работы

- **Интерактивный режим**: Пrompt-меню для выбора опций
- **Неавторизованный режим (-Unattended)**: Автоматическое выполнение всех шагов
- **Режим обновления (-PatchExistingWim)**: Только обновление существующего образа
- **Режим отладки (-DebugBuild)**: Полный вывод DISM и диагностика

### 4. Интеграция с SCCM

- Автоматический импорт в SCCM через PowerShell модуль
- Поддержка создания и обновления пакетов
- Управление дистрибутивными точками (DPs)

## Архитектурные особенности

1. **Модульность и фазы**:
   - Разделение на логические фазы (mount, cleanup, update, language injection и т.д.)
   - Каждая фаза выполняется последовательно

2. **Проверки и обработка ошибок**:
   - Проверка свободного места на диске
   - Обработка ошибок DISM (0x800f0952 и др.)
   - Гибкая обработка ошибок в каждом шаге

3. **Архитектурная поддержка**:
   - Синхронизация для x64 и ARM64
   - Разные правила для ARM64 (только NetFx3)

4. **Кэширование**:
   - Сохранение скачанных обновлений
   - Автоматическое использование кэша на последующих запусках

5. **Гибкость**:
   - Параметры по умолчанию и опциональные параметры
   - Возможность кастомизации через XML-файлы

## Важные версии и изменения

- Добавлен параметр -WindowsISOPath для точного указания Windows ISO
- Корректировки для ARM64 поддержки
- Улучшенная обработка ошибок DISM
- Новая логика для сборки Insider Preview ISO

## Использование

Скрипт предназначен для системных администраторов, которые:
- Развертывают Windows 11
- Требуют гибкой настройки образа
- Обновляют образы на регулярной основе
